## Status words

- **Passed** — the deadline is before October 19, 2026. This repo has no submission on file.
- **Upcoming** — deadline is still ahead, and this repo has no submission on file.
- **Open, not a commitment** — the funder is accepting applications. This project has not decided to apply.
- **Waiting on LOI** — happens only after the letter of intent is in.
- **Invite only** — the full proposal is not open unless Honoraria invites the project.
- **Working target** — the cycle this project is aiming at. The date itself is posted by the funder.
- **On the LOI timeline** — taken from the 2027 Honoraria letter-of-intent page, which does not give a day.

## Funding shape for the Honoraria ask

From the [Honoraria program FAQ](https://burningman.org/black-rock-city/bring-your-art/art-grants-programs/brc-honoraria/), checked October 19, 2026:

- Request 40–60% of the total budget. Burning Man typically funds that share and strongly recommends partial funding.
- Grants over $20,000 are rare. A request of $30,000 or higher should include budget tiers, including a lower one.
- The ~$80,000 figure in `budget.md` is the planning total. The FAQ's recommended request is 40–60% of the project total.
